# Word 世界 · UI／UE／UX 设计方案

版本：0.3（原型设计基线） · 日期：2026-10-10

## 1. 设计方向

采用“探索地图＋乒乓球训练基地”。首页以今天要做什么为中心，地图作为可选入口，避免孩子找任务时先经过复杂场景。

视觉建议：深蓝作为文字和训练基地底色，青绿作为主要操作色，暖黄色用于奖励，珊瑚色用于需关注的提示。学生学习页使用浅色背景，保证题目清晰。成绩反馈同时包含文字和图标，不能只靠红绿辨别。

弟弟主题“大图启蒙”：图形突出、读屏提示、主操作触控区域建议至少 48×48 CSS 像素。姐姐主题“探索训练”：更简洁的地图、球拍与任务卡。初高中主题“学习工作台”：沿用导航，减少角色与动画。

字体优先系统中文字体，英文选用易辨认字形；正文建议 16–18px，题目 22–28px。正常文字对比度目标至少 4.5:1。音频不自动播放，首次点击后再按浏览器能力启用。

## 2. 页面结构

| 区域 | 页面 | 主操作 |
|---|---|---|
| 家庭 | 登录／家庭入口 | 家长登录、孩子登录名登录／设备配对、选择孩子、进入家长区 |
| 学生 | 今日学习 | 继续任务或开始短计划 |
| 学生 | 探索地图／教材 | 选择单元或启蒙主题 |
| 学生 | 学习与辅导 | 听讲解、查看提示、完成练习 |
| 学生 | 训练基地 | 日常赛、月赛、季度赛、未完成比赛 |
| 学生 | 比赛／小结 | 答题、休息续赛、进入巩固 |
| 学生 | 我的成长 | 周目标、连续打卡、月历、徽章、积分与补签卡 |
| 学生 | 家庭奖励 | 查看奖励、申请兑换、查看兑现与积分明细 |
| 家长 | 奖励管理 | 设置奖励、处理申请、登记兑现与撤销 |
| 家长 | 家庭总览 | 查看两个孩子、调整计划 |
| 家长 | 孩子报告 | 看进度、薄弱项、推荐原因 |
| 家长 | 设置 | 教材、目标、设备和数据管理 |

手机学生导航：今日、探索、训练、成长；家长导航：总览、报告、设置。家长区与学生区采用不同页面标题，返回学生区始终可见。

## 3. 核心流程

### 弟弟零基础，约 10 分钟

选择弟弟 → 今日“认识身边的颜色”（自建演示主题） → 听音看图 → 选图练习 → 跟读与自评 → 简短巩固 → 小结。

每屏只安排一个主要动作，播放按钮重复可用。不会时选择“再听一次”或“给我提示”，不用计时催促。小结用“今天认识了哪些内容”，避免将自评写成 AI 评分。

### 姐姐综合学习，约 15–20 分钟

选择姐姐 → 今日计划与推荐原因 → 到期复习 → 教材讲解 → 听力／阅读／句型练习 → 小结；训练基地可接续乒乓球比赛。

原型中教材卡显示已确认教材名称，但单元内容标注“演示内容，待目录核实”。不能凭封面编造真实单元名。

### 乒乓球日常赛

训练基地 → 显示“三局两胜、每局至少 11 分且领先 2 分” → 开始或继续 → 提交答案 → 简短讲解 → 下一回合 → 局间休息 → 赛后总结。

比分持续可见：孩子分数、系统陪练分数、比赛局分。10:10 显示“领先 2 分才能赢”；11:10 显示“还需要领先 2 分”。中途休息显示“进度已保存”，若尚未同步则写“已保存在此设备，等待同步”。

### 家长查看与调整

家庭入口 → 家长 PIN → 两名孩子的周概览 → 姐姐／弟弟报告 → 调整单次时长与周目标 → 预览下次计划 → 保存。

调整教材时提醒新计划会变化，历史记录仍保留在原教材版本。设置失败不提前展示成功状态。

### 连续打卡与补签

学习达标 → 自动打卡 → 小结显示本次积分与连续天数 → 有里程碑时展示徽章。成长页月历用文字与图形区分“实际学习”“补签”“未打卡”。漏签提示采用“今天可以重新出发”，不扣已有奖励。

成长页 → 选择可补日期 → 展示消耗 1 张卡、剩余卡数和恢复后的连续天数 → 确认 → 联网成功后更新。不可补日期显示原因。周必需学习量完成后出现可跳过的掉落动画，并写明“完成本周学习量，获得补签卡 ×1”，不是随机抽奖。

### 积分兑换与线下兑现

成长页 → 家庭奖励 → 选择奖励 → 查看价格／徽章条件 → 提交申请 → 等待家长。孩子页面明确“申请不会立即扣积分”。

家长奖励管理 → 选中孩子与申请，或直接登记 → 填写奖励、积分与备注 → 查看扣分后余额 → 确认已线下兑现 → 展示成功与流水。待处理、余额不足、未达到徽章资格、已兑现和已撤销各有明确状态。已兑现详情允许家长填写原因并撤销，确认退回原积分，记录持续可见。

## 4. 关键页面草图说明

**学生首页**：顶部头像、昵称和同步状态；主卡“今天约 15 分钟”与唯一显著按钮“开始／继续”；下面展示任务构成和周目标；地图与比赛入口位于次要区域；连续天数作为轻量提示，不抢占开始学习按钮。

**学习页**：顶部当前孩子、任务进度与退出；中央题目或材料；下方答案区；底部提示／重听及提交。提交后锁定已计分答案，展示讲解，再进入下一题。退出确认针对未提交作答，不阻止已保存进度离开。

**比赛页**：顶部局分和当前比分；中央球台的简化视觉与题目，避免动画遮挡；底部答案与提交；角落提供休息。声音、动画都不承担唯一信息传递功能。

**家长总览**：姐姐、弟弟各一张卡，分别显示本周有效分钟、目标、最近学习与一条建议；不显示谁更优秀。进入报告后提供周／月切换和统计说明。

**成长与奖励页**：显示积分余额、连续学习、徽章和补签卡数量；家庭奖励为子页面，不增加手机一级导航。积分明细同时显示赚取与消费，徽章在兑换后保留。

**家长奖励管理**：各孩子独立余额；待处理申请、已兑现记录及“直接登记”入口；确认页突出当前孩子、扣分金额、剩余余额和备注，提交中禁止再次操作。退款以撤销记录呈现，不隐藏原消费。

## 5. 响应式行为

| 设备布局 | 行为 |
|---|---|
| 手机竖屏 | 单列、底部导航；题目先于装饰；报告卡纵向排列 |
| 手机横屏 | 优先保留题目与答案；收起地图装饰，允许页面自然滚动 |
| 平板横屏 | 学习材料与练习适度分栏；比分与进度放侧栏 |
| 平板竖屏 | 主学习区单列，导航与内容随可用宽度调整 |
| 电脑 | 左侧导航、中央内容；报告可并列显示，但限制阅读行宽 |

按实际内容宽度切换布局，不按设备型号锁定。横竖屏切换、软键盘弹出不重建学习会话；核心按钮不能被固定栏或安全区域遮住。所有操作支持点击与键盘，不依赖悬停、拖拽或全屏能力。

## 6. 必须展示的异常状态

- 空数据：说明还没有学习记录，给出第一次学习入口。
- 内容未上线：标注课程状态，不伪造题库和进度。
- 加载／请求失败：可重试，已答内容不清空。
- 离线／待同步：保留本地进度，说明哪些功能暂不可用。
- 登录过期：保存未同步事件，再引导家长重新登录；不丢弃记录。
- 音频失败／拒绝麦克风：提供文字或其他练习入口，不显示虚假评分。
- 多设备比赛冲突：显示另一设备已推进，刷新后接续，避免重复回合。
- 题库不足：明确进入巩固回合或暂停，不改变比分与胜利规则。

## 7. 原型交付与试用

下一份交付为可点击演示原型，覆盖家庭入口、两种学生首页、启蒙练习、姐姐综合任务、比赛／续赛、学习小结、家长总览与计划设置。增加孩子独立登录、连续打卡／补签、积分奖励申请及家长线下兑现流程。包含手机和宽屏布局，原型明确标注演示数据及尚未实现的云功能。

家庭试用观察：孩子能否独立开始；是否理解提示和比分；愿不愿意在结束后再来；家长能否看懂进步并修改计划。重点记录卡住的步骤，不只询问“好不好看”。

原型评审后定下视觉和流程，再开发真实认证、同步、内容管理与学习功能。

## 8. 周／月任务考核界面

学生今日页从周计划中取短任务。成长页提供周／月切换，按新学、听说、阅读／写作、复习分别展示数量进度，并单独显示质量状态。显示“学习量已完成，等周末小检查”，而不是仅靠分钟进度宣称达标。

家长报告展示目标与实际数量、首次检查和补测结果、延迟复习结果以及待评估口语／写作；有效时长放在辅助信息区。支持调整下期任务，本期变更展示记录和原因。补签只改变签到月历，不推进任务进度。

周检查未通过时以“这些内容还需要巩固”引导短辅导和新题补测，不撤回学习量积分。月检查可分段完成并恢复进度，不能要求孩子连续完成长考试。原型必须覆盖学习量已完成但质量待验证／待巩固、样本不足和全部达标等状态。

## 9. 第二轮视觉修订：卡通冒险营地

根据家庭反馈，首轮的信息面板过于成人化，学生端改为原创卡通冒险营地：天空、山丘、学习小屋、乒乓球场与猫咪陪练“小沃”。点击小屋开始学习，点击球场进入训练；触屏和键盘均可操作，主要入口另有明确文字按钮。

学生导航改为营地、探索、训练和背包；任务列表转为短关卡路线，积分与连续天数转为轻量游戏状态条。采用柔和天空蓝、紫色、奶油黄、描边和有按压反馈的按钮。陪练对话替代长说明，学习质量与进度仍保留，避免为了游戏化掩盖学习结果。

家长端保持清晰管理风格。此次原型先验证小学卡通方向，初高中主题仍待独立设计。角色、场景为原创 SVG，不使用商业游戏素材；未引入动画循环或自动播放音效。

### 图标风格修订

导航、关卡、积分、奖励与陪练提示使用原创 SVG 图标，替换系统 emoji。采用统一几何轮廓、柔和渐变、受控高光和一致的图形尺寸；不依赖设备 emoji 字体。图标配合文字，装饰图标对辅助技术隐藏，场景可操作区域保留可访问名称。

## 10. 游戏交互融合：大厅、探索与结算

参考蛋仔派对的圆润角色与装扮反馈、我的世界的方块探索和个人建造、和平精英的大厅入口层级与任务结算，形成原创英语探险营地，不复制既有游戏角色或素材。

大厅中央展示原创圆润探险搭档与等距方块浮岛；右侧为任务、装扮、奖励入口，底部为明确的开始按钮。点击学习小屋进入建造预览，点击球场开始训练。任务板展开后查看周／月数量和质量，避免把管理报告铺满大厅。

原型可切换三种装备配色、放置营地路牌并在当前浏览器保存。装扮与建造本轮免费演示，后续使用独立学习材料解锁，不扣家庭可兑现积分。结算页反馈学习收获，真实奖励仅在有效学习验证后发放。没有战斗、射击或社交大厅功能。

移动端竖屏采用缩放的场景和固定布局操作区，宽屏展开浮岛；不强制横屏，不要求孩子像操作游戏摇杆一样才能开始学习。减少动态效果设置继续生效。

## 11. 高质量体素美术基准

以用户提供的参考图为质量基准，重新生成原创完整体素浮岛主场景，包含词汇森林、巨型球拍竞技场、听力海岸、雪山与阅读城堡，以及前景探险角色和狐狸。素材保存为 prototype/assets/adventure-world.png。

主大厅采用场景底图＋真实 HTML 地图按钮、深蓝游戏状态栏、浅色任务面板和成长奖励栏。手机竖屏采用场景上方、任务下方的重新排版，宽屏同时展示地图与任务。素材中不包含界面文字，文字和按钮可独立响应。

本轮高质量美术重点完成大厅；练习、报告等页面仍沿用前轮原型，尚未达到参考图整套品质。背景人物为静态生成图，装备选择仅更新状态标签，不宣称实时角色换装。生成美术不是三维模型或可自由行走地图。
