# Word 世界 · 可点击设计原型

打开 index.html 可体验静态页面。也可以在本目录执行 `python -m http.server 4173`，在自己的运行环境浏览器访问该服务。

原型使用自建演示题，非真实教材内容。所有余额、比分、补签和兑现操作仅存于当前浏览器，不存在真实认证、云同步、AI 评分或学习计时。家长空间不设认证，仅用于评审。

体验路线：

1. 今日 → 开始小冒险 → 选择答案 → 确认 → 小结。
2. 训练 → 从 10:10 开始体验，11:10 不结束，12:10 获胜。
3. 姐姐的成长 → 补签 → 申请奖励 → 家长空间 → 填写备注兑现 → 撤销退款。
4. 切换弟弟 → 查看启蒙首页及图形练习。

姐姐是奖励交互演示账户，弟弟成长页为独立静态样例。计划设置弹窗仅展示设计，不实际修改目标。正式版将按家庭与孩子隔离数据，并保留完整积分流水。

验证：Chromium 自动化已检查学习流程、两分领先、比赛结束、补签、奖励申请、消费及退款、本地恢复、孩子切换和 390px 布局无横向溢出。尚未在真实手机／平板或 Safari 验证。

desktop.png、mobile.png 为布局截图。正式原型仍需家庭试用；本次未发布网站、未提交 GitHub。

第二轮已改为卡通冒险营地。点击学习小屋／球场，或使用关卡按钮进入流程；学生导航为营地、探索、训练和背包，家长端保留管理布局。

第三轮改为游戏大厅：原创圆润角色、方块浮岛、任务板、装扮试穿、建造路牌和学习结算。浏览器本地保存演示装备及装饰，未接入真实建造经济或学习奖励。

第四轮以用户参考图为美术质量基准，使用原创生成的体素浮岛底图重做大厅。所有地图入口、任务和状态栏为真实 HTML 交互，手机竖屏重新布局。背景人物为静态图，装扮仅更新装备名称；其他学习／报告页面尚待统一美术。
